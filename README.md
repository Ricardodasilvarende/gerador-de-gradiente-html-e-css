# 🎨 Gerador de Gradientes Moderno

Um gerador de gradientes CSS simples, moderno e responsivo construído com HTML5, CSS3 e JavaScript puro.

## 🚀 Funcionalidades

- **Visualização em Tempo Real:** Veja o gradiente mudar instantaneamente conforme altera as configurações.
- **Tipos de Gradiente:** Suporte para estilos **Linear** e **Radial**.
- **Controle de Ângulo:** Ajuste o ângulo do gradiente linear de 0° a 360°.
- **Cópia Rápida:** Botão integrado para copiar o código CSS gerado diretamente para a área de transferência.
- **Interface Dark:** Design moderno otimizado para modo escuro.
